     1→# AppCraft Studio · 拖拽式 DIY App 制作工坊 — 工作日志
     2→
     3→## 项目愿景
     4→一个可视化拖拽 DIY App 平台：
     5→- 左侧「组件仓库」按 6 大目录分类（登录注册 / 商城 / 购物详情 / 即时聊天 / 外卖点餐 / 功能通用），60+ 小组件
     6→- 中间「手机画布」代表 App 界面，拖拽添加、排序、选中编辑
     7→- 多页面管理（每个界面可保存），页面之间自定义跳转连接（流程图可视化）
     8→- UI/UX 自定义（主题色 / 圆角 / 暗色模式）
     9→- 可「上架」应用（版本快照）+ 可交互预览
    10→
    11→## 技术方案
    12→- Next.js 16 App Router + TS + Tailwind 4 + shadcn/ui + zustand + framer-motion
    13→- Prisma SQLite：Project / Page / Connection / Publish
    14→- 仅 `/` 路由，客户端视图切换：home → editor → flow / preview
    15→- 组件契约：`WidgetDef { type, category, name, desc, icon, defaultProps, fields, render(props), fullBleed? }`
    16→- 画布通过 CSS 变量下发主题：`--p` 主色 / `--pr` 圆角 / `--pf` 主色上文字；`.pd` 类 = 预览暗色；`w-card/w-input/w-chip/w-line` 为明暗自适应表面类（globals.css）
